# Color Theme (System / Light / Dark) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the clinician choose **System / Light / Dark** in Settings. The default is System. Dark mode must look exactly as it does today.

**Architecture:** The app hard-codes the dark palette in about 400 Tailwind classes (`text-slate-400`, `bg-cyan-950/60`, ...). Instead of editing every class, the Tailwind colors become CSS variables (`rgb(var(--c-slate-400) / <alpha-value>)`). Dark values are Tailwind's own defaults. Light values are the mirrored shade of the same palette (`slate-100` becomes the value of `slate-900`, and so on), so every existing class flips with the theme. A `data-theme="light|dark"` attribute on `<html>` selects the variable set. A small inline script sets it before first paint, and `src/lib/theme.ts` keeps it in sync. A handful of classes that do not mirror safely are fixed by a sweep, and a guard test keeps them fixed.

**Tech Stack:** React 19, Tailwind 3.4, Vitest 4. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-17-perioperative-guide-design.md` (§2 Settings additions; Task 4 records this). The theme is not in the spec yet; it was requested after the spec was approved.

## Scope decisions (read first)

- **Separate from the plan cards.** Run this plan first, then `2026-11-17-plan-cards.md`. Both edit `App.tsx` lightly.
- **Stored in its own key** `anesthassist-theme` (`light` or `dark`; **no key means System**). It is **not** part of the Zustand persisted store, so the persist `version` stays 4 and nobody's checklist ticks are wiped. This follows the modern-web-guidance `dark-mode-toggle` guide.
- **Three explicit options** (System, Light, Dark) because they live in the Settings sheet, where the guide allows it. There is no toggle in the header.
- **System follows the OS live.** A stored Light or Dark is never removed when the OS changes.
- **The SOS emergency overlay stays dark in both themes.** It is a crisis screen with red-on-dark contrast, and a bright full-screen flash in a dim OR is a hazard. Flip it by deleting one attribute (Task 3 Step 5). **This is a design call for the clinician to confirm.**
- **The installed-app splash and manifest `theme_color` stay dark.** The manifest is static. The browser tab color follows the theme through `<meta name="theme-color">`.
- **Left out:** a header toggle, a high-contrast mode, per-component themes, scheduled (time-of-day) switching.

**Mirror rule (why it is safe):**
- **Slate mirrors fully** (`50↔950`, `100↔900`, `200↔800`, `300↔700`, `400↔600`, `500` stays). That keeps text readable: the computed contrast of `text-slate-400` on the card surface is 6.7:1 in dark mode and about 6:1 in light.
- **Accent families** (`cyan amber emerald red violet sky`) mirror `50-300` and `700-950` only. **Shades 400-600 stay identical in both themes**, because solid buttons (`bg-cyan-500 text-black`, `bg-red-500 text-white`) must keep their meaning.
- Text in an accent at shade 400 would be unreadable on light, so Task 3 changes the 13 `text-<accent>-400` uses to `-300`, which does mirror.

## Global Constraints

- Offline-first PWA. No new dependencies. No network calls.
- **Dark mode pixel parity:** the dark variable values equal Tailwind's default colors and the old `clinical.*` hexes. A test pins this.
- Contrast: body text pairs must be at least 4.5:1 in **both** themes (tested). Touch targets stay at least 48 px.
- Tailwind 3. Literal class strings only. No `dark:` variants (none exist today).
- Do not bump the Zustand persist `version`. Do not touch `partialize`.
- Run only the affected test file first, then `npm run verify` before finishing.
- **Tasks must run in order (1, 2, 3, 4).**
- Work in your own worktree on your own branch. Skip any `git switch`/`git checkout` step, and never touch the main checkout.

## Review Focus

- **Dark mode unchanged.** Task 1 pins every dark value against Tailwind's defaults.
- **Light text is readable.** Task 1 pins slate 100-400 and accent 100-300 text on every surface at 4.5:1.
- **Solid accent buttons keep dark text on light.** Task 3's sweep replaces `text-slate-950` (which would mirror to near-white) with `text-black`; Task 3's guard test pins it.
- **System preference changes apply live, and a stored choice is never auto-cleared.** Task 2 tests the resolver and the storage rules.
- **A bad or missing stored value means System, and blocked storage still applies the theme.** Task 2 pins both.
- **No flash of the wrong theme.** Task 2 pins that the inline script in `index.html` uses the same key and colors as `theme.ts`.
- **SOS overlay stays dark.** Task 3 Step 8 checks it by hand.
- **An unmapped color family cannot sneak back in.** Task 3's guard test rejects `gray/zinc/green/blue/...` utilities.

```ts
import { describe, expect, it } from 'vitest';
import { CLINICAL, FAMILIES, SHADES, colorTokens, shadeHex, themeVars, type Theme } from '../palette';

const THEMES: Theme[] = ['dark', 'light'];
const ACCENTS = FAMILIES.filter((f) => f !== 'slate');

const rgb = (hex: string): [number, number, number] => {
  const h = hex.replace('#', '');
  return [0, 2, 4].map((i) => parseInt(h.slice(i, i + 2), 16)) as [number, number, number];
};
const luminance = ([r, g, b]: [number, number, number]) => {
  const [R, G, B] = [r, g, b].map((v) => {
    const c = v / 255;
    return c <= 0.03928 ? c / 12.92 : ((c + 0.055) / 1.055) ** 2.4;
  });
  return 0.2126 * R + 0.7152 * G + 0.0722 * B;
};
const contrast = (a: [number, number, number], b: [number, number, number]) => {
  const [hi, lo] = [luminance(a), luminance(b)].sort((x, y) => y - x);
  return (hi + 0.05) / (lo + 0.05);
};
const mix = (a: [number, number, number], b: [number, number, number], alpha: number): [number, number, number] =>
```

```ts
import colors from 'tailwindcss/colors';

export type Theme = 'dark' | 'light';

export const SHADES = [50, 100, 200, 300, 400, 500, 600, 700, 800, 900, 950] as const;
export const FAMILIES = ['slate', 'cyan', 'amber', 'emerald', 'red', 'violet', 'sky'] as const;
type Family = (typeof FAMILIES)[number];

// Light-mode shade for each dark-mode shade. Slate mirrors fully so muted text stays readable.
const MIRROR: Record<number, number> = { 50: 950, 100: 900, 200: 800, 300: 700, 400: 600, 500: 500, 600: 400, 700: 300, 800: 200, 900: 100, 950: 50 };
// Accent families keep 400-600 so solid fills (buttons, chips) look the same in both themes.
const ACCENT_MIRROR: Record<number, number> = { ...MIRROR, 400: 400, 600: 600 };

export const CLINICAL = {
  dark: {
    bg: '#090d16', card: '#131b2e', border: '#1e293b', 'border-light': '#334155',
    cyan: '#06b6d4', red: '#ef4444', emerald: '#10b981', amber: '#f59e0b', purple: '#a855f7',
  },
  light: {
    bg: '#f8fafc', card: '#ffffff', border: '#e2e8f0', 'border-light': '#cbd5e1',
    cyan: '#0e7490', red: '#b91c1c', emerald: '#047857', amber: '#b45309', purple: '#7e22ce',
  },
} as const satisfies Record<Theme, Record<string, string>>;

const table = colors as unknown as Record<Family, Record<number, string>>;

export const shadeHex = (family: Family, shade: number, theme: Theme): string => {
  const map = family === 'slate' ? MIRROR : ACCENT_MIRROR;
  return table[family][theme === 'dark' ? shade : map[shade]];
};

/** "#rrggbb" to "R G B", the channel form Tailwind's `<alpha-value>` placeholder needs. */
const triple = (hex: string): string => {
  const h = hex.replace('#', '');
  return [0, 2, 4].map((i) => parseInt(h.slice(i, i + 2), 16)).join(' ');
};

export const themeVars = (theme: Theme): Record<string, string> => {
  const vars: Record<string, string> = {};
  for (const f of FAMILIES) for (const s of SHADES) vars[`--c-${f}-${s}`] = triple(shadeHex(f, s, theme));
  for (const [key, hex] of Object.entries(CLINICAL[theme])) vars[`--clinical-${key}`] = triple(hex);
  return vars;
};

export const colorTokens = (): Record<string, Record<string, string>> => {
  const out: Record<string, Record<string, string>> = {};
  for (const f of FAMILIES) {
    out[f] = Object.fromEntries(SHADES.map((s) => [String(s), `rgb(var(--c-${f}-${s}) / <alpha-value>)`]));
  }
  out.clinical = Object.fromEntries(Object.keys(CLINICAL.dark).map((k) => [k, `rgb(var(--clinical-${k}) / <alpha-value>)`]));
  return out;
};
```

```ts
import { useSyncExternalStore } from 'react';

export type ThemePreference = 'system' | 'light' | 'dark';
export type ResolvedTheme = 'light' | 'dark';

/** No stored value means System. Kept out of the Zustand store so its persist version is untouched. */
export const THEME_KEY = 'anesthassist-theme';
/** Browser tab color. The inline script in index.html carries the same two values. */
export const THEME_COLOR: Record<ResolvedTheme, string> = { dark: '#090d16', light: '#f8fafc' };

export const resolveTheme = (pref: ThemePreference, systemDark: boolean): ResolvedTheme =>
  pref === 'system' ? (systemDark ? 'dark' : 'light') : pref;

export const parsePreference = (raw: string | null): ThemePreference => (raw === 'light' || raw === 'dark' ? raw : 'system');

export const readPreference = (store: Pick<Storage, 'getItem'> | null): ThemePreference => {
  try {
    return parsePreference(store?.getItem(THEME_KEY) ?? null);
  } catch {
    return 'system';
  }
};

export const writePreference = (store: Pick<Storage, 'setItem' | 'removeItem'> | null, pref: ThemePreference): void => {
  try {
    if (pref === 'system') store?.removeItem(THEME_KEY);
    else store?.setItem(THEME_KEY, pref);
  } catch {
    /* storage blocked: the choice still applies for this session */
  }
};

export const applyTheme = (
  root: { dataset: Record<string, string | undefined> },
  meta: { content: string } | null,
  theme: ResolvedTheme,
): void => {
  root.dataset.theme = theme;
  if (meta) meta.content = THEME_COLOR[theme];
};

// ---- browser wiring (not unit-tested: it only connects the pure functions above to the page) ----

const safeStorage = (): Storage | null => {
  try {
    return localStorage;
  } catch {
    return null;
  }
};
const systemQuery = (): MediaQueryList | null => (typeof matchMedia === 'function' ? matchMedia('(prefers-color-scheme: dark)') : null);

let preference: ThemePreference = 'system';
const listeners = new Set<() => void>();

const apply = () => {
  // No matchMedia: stay dark, which is what the app looked like before themes existed.
  const systemDark = systemQuery()?.matches ?? true;
  applyTheme(document.documentElement, document.querySelector('meta[name="theme-color"]'), resolveTheme(preference, systemDark));
  listeners.forEach((l) => l());
};

/** Call once, before React renders. Follows OS changes while the preference is System. */
export const initTheme = (): void => {
  preference = readPreference(safeStorage());
  apply();
  systemQuery()?.addEventListener('change', apply);
  // Another tab changed the choice.
  window.addEventListener('storage', (e) => {
    if (e.key !== THEME_KEY) return;
    preference = parsePreference(e.newValue);
    apply();
  });
};

export const setThemePreference = (pref: ThemePreference): void => {
  preference = pref;
  writePreference(safeStorage(), pref);
  apply();
};

const subscribe = (l: () => void) => {
  listeners.add(l);
  return () => listeners.delete(l);
};

export const useThemePreference = (): ThemePreference => useSyncExternalStore(subscribe, () => preference);
```

```ts
import { join } from 'node:path';
import { describe, expect, it } from 'vitest';

const SRC = fileURLToPath(new URL('../..', import.meta.url));
const files = (dir: string): string[] =>
  readdirSync(dir).flatMap((n) => {
    const p = join(dir, n);
    if (n === '__tests__') return [];
    return statSync(p).isDirectory() ? files(p) : p.endsWith('.tsx') ? [p] : [];
  });
const sources = files(SRC).map((p) => ({ p: p.slice(SRC.length), text: readFileSync(p, 'utf8') }));
const offenders = (re: RegExp) => sources.filter((s) => re.test(s.text)).map((s) => s.p);

describe('classes that would break in light mode', () => {
  it('no text-slate-950: it mirrors to near-white and would vanish on solid accent buttons; use text-black', () => {
    expect(offenders(/text-slate-950/)).toEqual([]);
  });

  it('no hard-coded page or card hex: use bg-clinical-bg and bg-clinical-card so they follow the theme', () => {
    expect(offenders(/\[#(090d16|131b2e)\]/)).toEqual([]);
  });

  it('no accent text at shade 400: it is unreadable on light; use shade 300, which mirrors', () => {
    expect(offenders(/\btext-(red|amber|cyan|emerald|violet|sky)-400\b/)).toEqual([]);
  });

  it('no hover:text-white on a themed surface: it would vanish on light; use hover:text-slate-100', () => {
    expect(offenders(/hover:text-white/)).toEqual([]);
  });

  it('only color families that the theme maps (slate, cyan, amber, emerald, red, violet, sky, clinical)', () => {
    const unmapped = /\b(?:bg|text|border|ring|from|to|via|fill|stroke|divide|outline|accent|caret|placeholder)-(?:gray|zinc|neutral|stone|orange|yellow|lime|green|teal|blue|indigo|purple|fuchsia|pink|rose)-\d{2,3}\b/;
    expect(offenders(unmapped)).toEqual([]);
  });
});
```
