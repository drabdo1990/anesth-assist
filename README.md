# AnesthAssist

AnesthAssist is an offline anesthesia dosing and crisis cognitive aid, delivered as a mobile-first Progressive Web App. It has four tabs: Calculator (weight-based drug doses from biometric scalars), Crisis (LAST, malignant hyperthermia and cannot-intubate/cannot-oxygenate protocols), Local Max (combined local anesthetic maximum checker) and Checklists (WHO, extubation and PACU handoff).

## Commands

```
npm run dev       # Vite dev server
npm run build     # tsc --noEmit, then vite build (emits service worker and manifest)
npm run test      # Vitest unit tests (run once)
npm run preview   # serve the production build on the local network
npm run icons     # regenerate PWA icons (scripts/make-icons.mjs)
```

## Privacy design

- No network calls, no accounts, no telemetry, no PHI. All calculation runs on the device.
- Persisted to localStorage under the key `anesthassist-v1`: `weightKg`, `heightCm`, `sex`, and per-drug vial concentration overrides. Nothing else is persisted.
- In memory only, lost on reload: checklist ticks, timers, local-anesthetic entries and PACU text.
- The PACU form has no identifier fields and asks users not to enter names, MRNs or DOBs.

## Where the clinical constants live

- `src/lib/drugs.ts`: drug catalogue (doses, scalars, vial concentrations, maximums).
- `src/lib/localAnesthetics.ts`: local anesthetic maximum doses and absolute ceilings.
- `src/lib/crisis.ts`: LAST, dantrolene and Ryanodex calculators, CICO step data.
- `src/lib/checklists.ts`: WHO, extubation and PACU templates.

Values not taken from the original specification are marked `source: 'added'` in these files and listed in spec section 9 for clinical review.

## Clinical disclaimer

AnesthAssist is an educational cognitive aid. It is not a validated medical device. Every constant must be verified by a clinician against local protocols before any real use. Formulas are adult-oriented. Clinical judgment supersedes all calculated suggestions.

## Offline support

Offline use is provided by a service worker generated by vite-plugin-pwa with `registerType: 'autoUpdate'`. It precaches all built assets. It is registered only in a production build, so test offline behaviour with `npm run build` followed by `npm run preview`.
