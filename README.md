# AnesthAssist

AnesthAssist is an offline anesthesia dosing and crisis cognitive aid, delivered as a mobile-first Progressive Web App. It has four tabs: Calculator (weight-based drug doses from biometric scalars), Crisis (LAST, malignant hyperthermia and cannot-intubate/cannot-oxygenate protocols), Local Max (combined local anesthetic maximum checker) and Checklists (WHO, extubation and PACU handoff).

## Commands

```
npm run dev       # Vite dev server
npm run build     # tsc --noEmit, then vite build (emits service worker and manifest)
npm run test      # Vitest unit and component tests (run once)
npm run lint      # Biome lint + format check
npm run format    # Biome auto-fix (format and safe lint fixes)
npm run preview   # serve the production build (localhost only unless --host is added)
npm run icons     # regenerate PWA icons (scripts/make-icons.mjs)
```

The pure calculation layer in `src/lib` is covered by unit tests; the components and views have jsdom
tests (`.test.tsx`). `npm run lint` (Biome) and `tsc --noEmit` both run in CI before any deploy.

## Privacy design

- No network calls, no accounts, no telemetry, no PHI. All calculation runs on the device.
- Persisted to localStorage under the key `anesthassist-v1`: `weightKg`, `heightCm`, `sex`, and per-drug vial concentration overrides. Nothing else is persisted.
- In memory only, lost on reload: checklist ticks, timers, local-anesthetic entries and PACU text.
- The PACU form has no identifier fields and asks users not to enter names, MRNs or DOBs.

## Where the clinical constants live

- `src/lib/drugs.ts`: drug catalogue (doses, scalars, vial concentrations, maximums).
- `src/lib/localAnesthetics.ts`: local anesthetic maximum doses and absolute ceilings.
- `src/lib/crisis.ts`: LAST, dantrolene and Ryanodex calculators, CICO step data.
- `src/lib/checklists.ts`: WHO, extubation and PACU templates.

Values not taken from the original specification are marked with `// added` comments in these files and listed in spec section 9 for clinical review.

## Clinical disclaimer

AnesthAssist is an educational cognitive aid. It is not a validated medical device. Every constant must be verified by a clinician against local protocols before any real use. Formulas are adult-oriented. Clinical judgment supersedes all calculated suggestions.

## Offline support

Offline use is provided by a service worker generated by vite-plugin-pwa with `registerType: 'autoUpdate'`. It precaches all built assets. It is registered only in a production build. Service workers need a secure context (HTTPS or localhost): `npm run preview` on localhost works for testing, but a plain `http://192.168.x.x` address from a phone does NOT register a service worker, so serving over the local network cannot test offline use. Real devices need HTTPS hosting. An offline reload on a real device has NOT been verified yet and must be done before any real use.

## Items needing clinician review

- The lipid infusion is dosed on total body weight at 0.25 mL/kg/min as specified and may be very high for large patients (ASRA suggests roughly 200-250 mL over 15-20 min above 70 kg).
- CICO Plan C wording was changed in the final review: it is now two branches (face-mask ventilation possible: oxygenate and wake with sugammadex; not possible: confirm blockade, no sugammadex, go to Plan D). This wording needs clinician review.
